# Voron-Stealthburner — pitfalls
- Looking for the X carriage here — it's in each printer repo (SB STLs/README.md says so explicitly).
- Mixing cw1 rear half with a Clockwork2 build (rear_cw1 files exist only for a couple of printheads).
- Using plain chain_anchor_2hole/3hole on a Switchwire (needs _SW variants).
- Hole-count mismatch: SB chain_anchor_3hole with Trident z_lower_2hole.
- Attaching SB to a Voron-0 (V0 = Mini SB, in Voron-0 repo).
- Treating [o]_/[c]_ LED parts as optional duplicates — they're print-in-different-material variants.
