# LDOVoron2 — pitfalls
- Printing plug_panel_1.2mm on a V2.4R2 build — README marks it deprecated for that revision.
- Following the repo's own README links to upstream paths (STLs/VORON2.4/...) — those are V2.4r1-era and 404 against Voron2.4 HEAD layout.
- Selecting nozzle_probe_ldo together with Tap.
- Treating this repo as the printer: it holds ~a dozen supplement parts, not a V2.4.
