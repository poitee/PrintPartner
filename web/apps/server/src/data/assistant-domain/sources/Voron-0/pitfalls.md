# Voron-0 — pitfalls
- Treating `Voron0.2r1` as a tag — it's the default BRANCH; tags stop at V0.1.
- Attaching full-size Voron-Stealthburner to a V0 — the V0 uses the in-repo Mini Stealthburner (STLs/Toolheads).
- Adding Voron-Tap: V0 beds are explicitly not rigid enough (Tap README).
- Selecting both Multibody_STLs alternates and the normal single-body parts.
- Selecting both Picobilical and pancake-board toolhead PCBs.
- Missing case-sensitive extensions (.STL vs .stl) when globbing.
