# Voron-Switchwire — Print Partner workflow
1. Add `Voron-Switchwire`; **Sync**. Default branch `master`; tag `V1.0` to pin; avoid `switchwire_afterburner` for new builds.
2. Attach as **base**; addons: `Voron-Stealthburner` (with _SW chain anchors), `LDOVoronSW@s1` for the LDO kit, optional `Klicky-Probe` (Switchwire scope).
3. Manifest selections: controller mount variant, filtered vs plain grills, LCD parts.
4. Remember STL root is `STL/`, not `STLs/`, when mapping paths.
5. **Sync after changing tag.**
