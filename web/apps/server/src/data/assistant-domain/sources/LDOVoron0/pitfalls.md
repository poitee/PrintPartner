# LDOVoron0 — pitfalls
- Using branch `main` — kit content lives on v01/v02/v02r1; default is v02r1.
- Double-counting: Preset_Print_PlatesR1 plates contain parts that also exist individually (here and in Voron-0).
- Selecting Picobilical_Toolhead parts without the LDO-Picobilical addon (or vice versa).
- Forgetting this repo replaces stock parts (inlet foot, one skirt) — deselect the stock versions in Voron-0.
