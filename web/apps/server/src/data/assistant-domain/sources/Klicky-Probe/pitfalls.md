# Klicky-Probe — pitfalls
- Attaching the whole repo: includes Ratrig/Tiny-M/ZeroG printers and 4 probe flavors.
- Mixing probe flavors (KlickyProbe vs KlickyNG parts don't interchange).
- Using the v0 mount set on a V2/Trident (folder scoping matters).
- Combining with Tap on one stack.
- README warns it's 'an intermediate/advanced configuration' — build stock first.
