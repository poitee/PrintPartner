# Keep Sources and Plan State Contextual

Sources answers whether the Build inputs are ready; Plan owns Working Plan creation, comparison, required-unit choices, and publication. Sources therefore cannot receive Accepted Plan review issues, accepted part counts, Plan freshness, or Working Plan lifecycle state. This makes the valid first-publication state—no published revision alongside a populated Working Plan—unambiguous and prevents Accepted Plan facts from appearing as Source file problems. The interface uses concrete choices and publication outcomes instead of generic blocker labels. MCP research, checklists, and assistant review notes are advisory Preparation data: MCP cannot create a publication blocker, and that data is absent from the Plan publication contract. The native Working Plan service remains the only authority that can publish a revision and continues to enforce snapshot, lifecycle, accepted-base, required-unit reconciliation, and active-work safety.
